# MOX ACCESS

## Работа с проектом

- Общайтесь с пользователем по-русски, с агентами — по-английски.
- Работайте с `main`. Не создавайте ветки без прямой команды пользователя.
- Для GitHub используйте `gh-axi`. Независимые задачи можно поручать агентам.
- Основное приложение — локальный MVP в `server/`. `dist/` — архивный прототип.
- Запуск MVP: `npm start`. Проверки: `npm test`. Архивное демо: `npm run demo`.
- Проверяйте интерфейс через Playwright MCP в отдельном браузере на десктопе и мобильных ширинах 320–1920 пикселей. Для видимого окна не задавайте размер страницы больше самого окна браузера. Не подключайте автоматизацию к основному Chrome пользователя.
- Реальный вход выполняет человек в обычном Chrome. Не закрепляйте профиль и не обходите проверки сайта.
- Публикация исходников не означает разрешение разворачивать общий сервер или делать платные запросы. Учитывайте явные разрешения текущей сессии.

## Правила MVP

- Данные и авторизация хранятся вне репозитория, в отдельных профилях MOX. Не импортируйте личный профиль оператора.
- Не публикуйте ключи, пароли, базу, профили, логи и локальные отчёты. Полный ключ показывается один раз; база хранит хеш и маску.
- Активный ключ бессрочный, действует до ручного отзыва и открывает все текущие и будущие подписки. Ключи не меняются при повторном входе в подписку. Не возвращайте раздел проверки ключа; раздел «Подключение API ключа» содержит отдельные инструкции для Desktop и CLI.
- Чат закреплён за подпиской. Проверяйте ключ и доступ перед каждым запросом, включая выход из очереди. Не переносите и не повторяйте запросы автоматически.
- Авторизация, пауза и квота — независимые состояния. Один ответ 429 не доказывает исчерпание недельного лимита.
- Недельную квоту определяйте по продукту `codex` и длительности окна. Не подменяйте её квотой другого продукта или датой оплаты.
- Расход считайте по сотруднику за календарные периоды Москвы. Неизвестные значения не превращайте в нули; отзыв ключа сохраняет историю.
- В MVP группы Fast отражают режим отправки запроса. Ответ провайдера хранится отдельно и не подтверждает фактическое ускорение автоматически.
- В архивном демо сохранена прежняя группировка по ответу провайдера. Не смешивайте демо и настоящие данные.
- При ошибке сохранения расхода останавливайте новые запросы до восстановления. Дождитесь завершения обработчиков перед закрытием базы.
- Не возвращайте удалённый блок рабочего пространства в боковую панель.
- Интерфейс панели не должен сообщать о Mac, локальном устройстве или способе размещения сервера. Сохраняйте необходимые настройки клиента внутри инструкций подключения; технические ограничения запуска описывайте в документации.

Пишите коротко и простым языком. Не добавляйте тесты, повторяющие реализацию; запускайте проверки, соответствующие изменению.
