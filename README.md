# MOX ACCESS

Локальный MVP для управления доступом сотрудников к Codex. Работает на Mac: администратор подключает подписки OpenAI и выдаёт сотрудникам личные ключи MOX.

## Возможности

- Подключение подписок через ручной вход в обычном Chrome.
- Выдача бессрочных личных ключей сотрудников и их ручной отзыв.
- Доступ каждого активного ключа ко всем подключённым подпискам.
- Остаток недельной квоты.
- Входные и выходные токены по сотрудникам за день, неделю и месяц.
- Разделение расхода на «Fast запрошен» и «Fast не запрошен».
- Сохранение подключений, ключей и истории после перезапуска.

Fast в отчёте означает режим отправленного запроса. Фактическое ускорение эта метрика не подтверждает.

## Запуск

Нужны macOS, Node.js 24+, установленный Codex и Google Chrome. Дополнительных npm-зависимостей нет.

```sh
git clone https://github.com/MOX-Studio/MOX-ACCESS.git
cd MOX-ACCESS
npm start
```

Откройте **http://127.0.0.1:4174**. Пароль администратора появится в файле `~/Library/Application Support/MOX ACCESS/admin-password.txt`.

Далее подключите подписку, добавьте сотрудника и выдайте ему ключ. Инструкция для Codex доступна в разделе «Подключение API ключа». Один ключ действует до ручного отзыва и открывает все текущие и будущие подписки.

## Статус

Проверены вход в Pro, реальные запросы движка Codex, отзыв ключа и сохранение данных. Интерфейс адаптирован для десктопа и телефона; проверены ширины 320–1920 пикселей. Автоматические проверки: `npm test`.

MVP работает на одном Mac. Общий сервер для нескольких компьютеров и работа с несколькими настоящими подписками ещё не проверены. Подключение зависит от текущего протокола Codex.
