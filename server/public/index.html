Подключение API ключа

Один личный ключ — для всех текущих и будущих подписок окружения.

1

Сохраните ключ на компьютере

Откройте Terminal, выполните команду ниже и вставьте выданный ключ при запросе. Ключ будет сохранён в отдельном приватном файле.

Команда для Terminal

            
2
Настройте Codex
В файле ~/.codex/config.toml добавьте или замените строку model_provider в начале файла, до разделов в квадратных скобках.
model_provider = "mox"
Затем добавьте блок ниже. Если настройки MOX уже есть, замените весь раздел model_providers.mox вместе с вложенным разделом auth.
Настройки для config.toml
Другие настройки сохраните. В блоке MOX удалите прежние строки env_key, requires_openai_auth и experimental_bearer_token, если они есть.

            
3
Перезапустите Codex
Полностью завершите приложение и откройте снова. Ключ будет читаться из файла автоматически, в том числе при запуске из Dock.

            
4
Откройте новый чат
Отправьте запрос. MOX выберет доступную подписку, а расход появится в разделе «Расход токенов». Каждый чат остаётся на выбранной подписке.

          

          
Доступ по ключу
Ключ бессрочный и действует до ручного отзыва. При добавлении подписок менять его не нужно.
Сейчас сервер работает на этом Mac. Этот адрес доступен только здесь; для другого компьютера потребуется общий сервер.
