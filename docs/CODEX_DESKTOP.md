# Подключение API ключа: Desktop и CLI

Один личный ключ MOX открывает все текущие и будущие подписки окружения. Он бессрочный и действует до ручного отзыва. Каждый новый чат получает доступную подписку и остаётся на ней.

Desktop и CLI на Mac используют общий файл ключа и настройки. Шаги 1 и 2 достаточно выполнить один раз.

## 1. Сохраните ключ на Mac

Выполните команду в Terminal. Вставьте ключ при запросе и нажмите Enter. Ввод скрыт; ключ не попадёт в историю команд.

```sh
zsh -c 'set -e
umask 077
mkdir -p "$HOME/.codex"
read -rs "mox_key?Вставьте ключ MOX и нажмите Enter: " || exit 1
print
if [[ ! "$mox_key" =~ "^mox_[0-9a-f]{64}$" ]]; then
  print "Нужен полный ключ MOX: mox_ и 64 символа после него."
  exit 1
fi
printf "%s" "$mox_key" > "$HOME/.codex/mox-access-key"
chmod 600 "$HOME/.codex/mox-access-key"
unset mox_key
print "Ключ сохранён."'
```

Ключ хранится в `~/.codex/mox-access-key` с правами `0600`. Не передавайте этот файл и не добавляйте его в Git.

## 2. Настройте Codex

В Desktop откройте **Settings → Configuration → User config → Open config.toml**. Для CLI можно открыть тот же файл командой `nano ~/.codex/config.toml`.

В `~/.codex/config.toml` добавьте или замените строку в начале файла, до разделов в квадратных скобках:

```toml
model_provider = "mox"
```

Добавьте блок ниже. Если настройки MOX уже есть, замените весь раздел `model_providers.mox` вместе с вложенным `auth`. Удалите из него прежние `env_key`, `requires_openai_auth` и `experimental_bearer_token`, если они есть. Другие настройки сохраните.

```toml
[model_providers.mox]
name = "MOX"
base_url = "http://127.0.0.1:4174/v1"
wire_api = "responses"
supports_websockets = false

[model_providers.mox.auth]
command = "/bin/sh"
args = ['-c', '/bin/cat "$HOME/.codex/mox-access-key"']
timeout_ms = 5000
refresh_interval_ms = 0
```

## Codex Desktop

После шагов 1 и 2 полностью завершите приложение через **⌘Q** и откройте его снова. Codex прочитает ключ из файла, в том числе при запуске из Dock. Создайте новый чат, выберите модель и отправьте запрос; расход появится в панели MOX.

## Codex CLI

После шагов 1 и 2 откройте Terminal в папке проекта и запустите:

```sh
codex
```

Введите сообщение в терминальном чате и нажмите Enter. Расход появится в панели MOX. Нужен установленный Codex CLI: [установка и обновление](https://learn.chatgpt.com/docs/codex/cli).

При замене ключа сохраните новый ключ командой из шага 1 и перезапустите используемый клиент. Адрес `127.0.0.1` доступен только на этом Mac. Общий сервер для других компьютеров ещё не развёрнут.
