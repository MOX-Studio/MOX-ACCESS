# Подключение Codex

Сотрудник работает в Codex и использует личный ключ MOX. Ему нужны ключ и адрес шлюза. Для текущего локального MVP адрес — `http://127.0.0.1:4174/v1`.

Добавьте в пользовательский `~/.codex/config.toml`:

```toml
model_provider = "mox"

[model_providers.mox]
name = "MOX"
base_url = "http://127.0.0.1:4174/v1"
env_key = "MOX_ACCESS_KEY"
wire_api = "responses"
requires_openai_auth = false
supports_websockets = false
```

Передайте личный ключ процессу Codex через переменную `MOX_ACCESS_KEY`. Не записывайте полный ключ в репозиторий или историю команд. Приложение, запущенное из Dock, не получает переменные из отдельного терминала автоматически.

На другом компьютере этот локальный адрес работать не будет. Общий удалённый сервер ещё не развёрнут.

## Что проверено

- Движок Codex 0.153.4 выполнил реальную файловую задачу через MOX и подключённую Pro.
- Отозванный ключ получил `401`, следующий проверочный ход Codex завершился отказом.
- Окно настольного приложения ранее проверялось с тестовым ответом сервера. Полный сценарий окна с реальной подпиской ещё не проверен.
