# Вход и расход токенов

## Вход в подписку

MOX получает ссылку входа от Codex и открывает обычный Chrome на компьютере сервера. Пользователь сам выбирает профиль и проходит авторизацию. Конкретный профиль Chrome в MOX не закрепляется.

Подписка появляется после подтверждения на сервере. Открытие или закрытие страницы само по себе не означает успешный вход. При повторном входе проверяется прежний аккаунт; неудачная попытка не заменяет рабочее подключение.

Для подписок используются отдельные профили MOX. Существующая личная авторизация оператора не импортируется. Сотрудники получают только свои ключи MOX.

## Учёт токенов

Панель показывает входные и выходные токены по сотрудникам за текущие день, неделю и месяц по Москве. Неделя начинается в понедельник. Отзыв или замена ключа сохраняют историю.

| Группа | Что означает |
| --- | --- |
| Fast запрошен | Codex передал запрос с Fast |
| Fast не запрошен | Запрос отправлен без Fast |
| Режим неизвестен | Не хватает сведений о режиме запроса |

Группировка описывает отправленный запрос. Она не доказывает фактическое ускорение со стороны OpenAI.

Счётчики берутся из ответов провайдера. Неизвестное значение не заменяется нулём. После обрыва или перезапуска незавершённый запрос не отправляется повторно автоматически.

В проверке пять реальных запросов дали 39 829 входных и 330 выходных токенов. Один запрос содержал Fast; провайдер во всех ответах указал обычный режим.

База хранит служебные сведения и счётчики. Тексты запросов, ответы и полные ключи в журнал расхода не записываются.
