# Запуск MVP

Нужны macOS, Node.js 24+, Codex и Google Chrome.

```sh
npm start
```

Панель откроется по адресу **http://127.0.0.1:4174**. Сервер доступен только на этом компьютере. Для остановки нажмите `Ctrl+C` в терминале.

## Первый вход

1. Возьмите пароль из `~/Library/Application Support/MOX ACCESS/admin-password.txt`.
2. Войдите в панель и нажмите «Подключить подписку».
3. Завершите вход OpenAI вручную в обычном Chrome.
4. Добавьте сотрудника и выдайте ему ключ. Полный ключ показывается один раз.

Для входа по коду устройства включите соответствующее разрешение в настройках безопасности **на сайте ChatGPT**.

## Где хранятся данные

Каталог `~/Library/Application Support/MOX ACCESS` содержит базу SQLite, пароль администратора и отдельные профили подключённых подписок. Не добавляйте этот каталог в Git и не передавайте его сотрудникам.

История сохраняется после перезапуска. Одновременно с одной базой работает один экземпляр сервера. Для резервной копии остановите сервер и скопируйте весь каталог данных.

## Настройки запуска

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `MOX_PORT` | Порт панели | `4174` |
| `MOX_DATA_DIR` | Каталог данных | `~/Library/Application Support/MOX ACCESS` |
| `MOX_CODEX_BIN` | Путь к движку Codex | `/Applications/ChatGPT.app/Contents/Resources/codex`, затем `codex` из PATH |

## Проверки

```sh
npm test
```

Тесты не обращаются к OpenAI. Реальная проверка выполняется отдельно, после подключения подписки, в интерактивном терминале:

```sh
npm run probe:mvp -- --key-file /path/to/private-key.txt
```

Если установлен только CLI, добавьте к команде `--codex codex`.

Файл ключа должен иметь права `0600`. Скрипт делает реальные запросы, затем ждёт отзыва ключа через панель. После отзыва введите `revoked` в терминале. Отчёты остаются в локальном каталоге `artifacts/`.

Проверены одна Pro-подписка, файловая задача в движке Codex, учёт токенов и отказ `401` после отзыва ключа. Полный сценарий окна настольного приложения с реальной подпиской пока отдельно не проверен.
